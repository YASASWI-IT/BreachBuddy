# BreachBuddy 🔐
### Privacy First. Security Always.

BreachBuddy is a Privacy-Preserving Breach Notification Assistant that helps users understand data breach notifications in simple language, identify potentially exposed personal information, understand indicative risk levels, and take recommended security actions.

## 🚀 Features

- **Simple Explanation:** Converts complex breach notifications into easy-to-understand language.
- **Data Exposure Detection:** Identifies potentially exposed information such as email addresses, phone numbers, passwords, bank details, and government IDs.
- **Risk Awareness:** Displays an indicative risk level based on detected information.
- **Recommended Actions:** Provides security suggestions based on potentially exposed data.
- **File Upload:** Supports PDF and TXT breach notifications.
- **Privacy Focused:** Processes notification content without storing it in a database.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS

- PyPDF

## 💻 Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YASASWI-IT/BreachBuddy.git
   ```

2. Open the project folder:

   ```bash
   cd BreachBuddy
   ```

3. Install the required packages:

   ```bash
   py -m pip install flask pypdf
   ```

4. Run the application:

   ```bash
   py app.py
   ```

5. Open your browser and visit:

   ```text
   http://127.0.0.1:5000
   ```

## 🔒 Privacy & Disclaimer

BreachBuddy processes the submitted notification for analysis and does not store it in a database. Its keyword-based analysis provides indicative results only. It cannot independently verify whether a data breach occurred or confirm the actual exposure of personal information.
